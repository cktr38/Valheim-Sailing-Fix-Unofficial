# Valheim Sailing Fix (Unofficial Build)

## What is this?

This is an **unofficial build** of the Sailing fix, compiled from the source code by [blaxxun-boop](https://github.com/blaxxun-boop/Sailing). The original author released fixes for Valheim 1.0 but did not publish a ready-to-use `.dll`. I compiled it from the source so players can use the fix without having to build it themselves.

## Installation

1. Download `Sailing.dll`.
2. Replace the old file in the `BepInEx/plugins/Smoothbrain-Sailing/` folder.
3. Done!

## Credits

All rights to the code belong to [blaxxun-boop](https://github.com/blaxxun-boop). I only compiled it into a ready-to-use `.dll`.
