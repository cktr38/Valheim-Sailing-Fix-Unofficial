# Valheim Sailing Fix (Unofficial Build)

## Что это?

Это **неофициальная сборка** фикса для мода Sailing, собранная из исходников автора [blaxxun-boop](https://github.com/blaxxun-boop/Sailing). Автор выложил исправления для Valheim 1.0, но не опубликовал готовый `.dll`. Я скомпилировал его, чтобы игроки могли использовать фикс без необходимости собирать его самостоятельно.

## Установка

1. Скачайте `Sailing.dll`.
2. Замените старый файл в папке `BepInEx/plugins/Smoothbrain-Sailing/`.
3. Готово!

## Благодарности

Все права на код принадлежат [blaxxun-boop](https://github.com/blaxxun-boop). Я лишь собрал его в готовый `.dll`.
